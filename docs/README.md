# Amuse Documentation

Amuse creates images, video, music, speech and text with AI, entirely on your own Windows PC. Nothing is uploaded, and there are no accounts or subscriptions.

This documentation covers every part of Amuse v4. Each guide has a short video followed by step-by-step instructions, screenshots and a reference for every option.

> New to Amuse? Start with [Installing Amuse](getting-started/installation.md), then follow [First run](getting-started/first-run.md) and [Your first image](getting-started/your-first-image.md).
